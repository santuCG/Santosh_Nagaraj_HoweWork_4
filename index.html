I have used CSS in this webpage, and there are three ways to include CSS in a webpage as follows:

  1. Inline CSS : Adding styles directly inside an HTML element using the STYLE attribute.
  2. Internal CSS : Defining styles within a STYLE tag in the HEAD section of the HTML document.
  3. External CSS : Linking an external CSS file using a LINK tag in the HEAD section.

The reasons CSS is used in the webpage are:

  1. Style and format the layout of the webpage.
  2. Enhance the visual appeal and user experience by applying colors and fonts.

We also use JavaScript in webpage development. The main reasons are as follows:
